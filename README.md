# 🏫 Sekolah Cerdas Nusantara (Archive - My First Website)

Repositori ini adalah kapsul waktu yang berisi *source code website* pertama yang saya buat. Proyek ini menjadi langkah pertama saya dalam memahami bagaimana elemen-elemen web disusun dan ditampilkan pada layar. 

Melihat kembali halaman statis ini adalah pengingat visual yang menyenangkan tentang titik awal perjalanan *coding* saya, terutama ketika membandingkannya dengan perancangan sistem saat ini yang sudah melibatkan kompleksitas arsitektur MVC, manipulasi *database*, dan logika *backend*.

## 🚀 Fitur Halaman
*   **Halaman Utama (Beranda):** Menampilkan profil singkat, daftar kegiatan sekolah, tabel jadwal pelajaran, dan area *login* siswa[cite: 1].
*   **Form Pendaftaran & Aktivitas:** Halaman form dasar yang menampilkan *input* pendaftaran serta rincian kegiatan[cite: 2].
*   **Integrasi Multimedia:** Penggunaan tag `<video>` HTML5 untuk memutar video secara lokal (© Kemdikbud - 2017) dan penataan aset visual gambar[cite: 1]
*   **Layouting Dasar:** Implementasi **CSS Flexbox** murni (tanpa *framework*) untuk membagi area konten secara berdampingan pada layar[cite: 1].

## 🛠️ Teknologi yang Digunakan
*   **HTML5** (Memanfaatkan tag semantik seperti `<header>`, `<nav>`, dan `<article>`)[cite: 1]
*   **CSS3** (Menggunakan *Internal CSS* untuk mengatur warna latar, *font*, *margin*, dan *shadow*)[cite: 1, 2]

## 📂 Struktur File Utama
*   `index.html` - Halaman utama antarmuka sekolah[cite: 1].
*   `Pendaftaran.html` - Halaman form pendaftaran[cite: 2].
*   `*.jpeg` / `*.jpg` - Kumpulan aset gambar (*background* dan thumbnail kegiatan)[cite: 1, 2].
*   `*.mp4` - Aset video literasi digital[cite: 1].

## 💡 Cara Menjalankan
Proyek ini sepenuhnya statis dan tidak memerlukan konfigurasi *server* lokal atau *database*.
1. *Clone* atau unduh repositori ini ke komputer.
2. Klik dua kali pada file `index.html` untuk membukanya langsung melalui *web browser* pilihan Anda.
